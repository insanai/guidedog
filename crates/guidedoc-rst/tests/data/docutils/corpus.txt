# Conformance corpus: one source per line, relative to this directory, followed by the
# settings it is read with. tools/rstref turns the settings into Docutils options when it
# stores the expected tree; tests/rst_conformance_test.odin turns them into rst.Settings.
#
#   sectsubtitle   promote lone subsection titles to section subtitles
#   smartquotes    typographic quotes, dashes, and ellipses (smartquotes-alt: the
#                  alternative quotation marks)
#   lang=TAG       document language
#   pep, rfc       implicit PEP and RFC references
#   trim           remove the space before footnote references
#   nodocinfo      no bibliographic fields
#   notitle        no document title
#   tab=N          tab width
#   charlevel      inline markup within words
#   nofile, noraw  no file insertion, no raw content
#   messages=total compare the number of problems, not their severity (a difference
#                  documented in lib/readers/rst/CONFORMANCE.md)
