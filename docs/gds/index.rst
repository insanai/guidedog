Guidedog Discussions
====================

A design record explains a decision and its consequences.
It names the assumptions, the alternatives, and the evidence.

**Read the state first.** A proposal is not an accepted design.
A Git commit is not the GDS state ``committed``.

This is a separate documentation project from the manual.
The manual teaches use. These records explain the design.
