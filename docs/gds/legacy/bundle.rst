Historical export manifest
==========================

The old bundle exported an HTML index, individual discussion pages, and PDFs.
Its targets belonged to the zenfmt repository. It depended on that repository's
Typst presentation helpers. Guidedog does not import those helpers.

This RST page records the purpose of the old entry point. The original source
remains in Git history. The historical registry preserves its target paths.

See :doc:`registry` for that data and :doc:`0001-zds-process` for the process.
