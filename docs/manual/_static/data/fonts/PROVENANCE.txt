Noto script web fonts for the Guidedog manual.

WOFF2 subsets preserve the upstream layout features, names, and glyph shapes.
The repertoire covers this manual. Missing glyphs use browser fallback fonts.
Complete regional CJK 2.003 faces and static Devanagari 2.006 faces, with sources
and checksums, are in docs/shared/fonts. Licenses accompany these subsets.
The subsets are publishing assets, not a Python runtime dependency.
