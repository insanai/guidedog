The CJK files are not kept in the repository (25 MB each): `cargo xtask fetch-fonts`
downloads them from the source above and checks the SHA-256 sums below.

These complete font files are for PDF, through pdf_font_paths. They are outside
html_static_path and are not downloaded by web readers. The manual web edition
uses WOFF2 subsets under docs/manual/_static/data/fonts; these retain shaping,
layout features, and upstream names. Missing web glyphs use system fallbacks.
