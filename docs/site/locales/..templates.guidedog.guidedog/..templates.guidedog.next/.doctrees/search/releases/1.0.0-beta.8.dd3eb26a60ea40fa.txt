guidedog-1-0-0-beta-8	Guidedog 1.0.0-beta.8	Guidedog 1.0.0-beta.8 We can now write Typst drawing source directly in an RST or MyST  typst-diagram  directive. Guidedog’s embedded compiler generates SVG or PNG and includes it in the website and PDF book. CeTZ and Fletcher use ordinary version-pinned imports, and local helper libraries work without a separate figure-generation task. Diagrams support captions, alternative text, names, classes, alignment and numbered figure references. Imported helpers and data files are tracked by content, and identical generated images keep their timestamps so unchanged books remain cached. The project package and font settings apply to both outputs. Untrusted builds retain source without executing Typst, and image export requires one finite page with bounded PNG dimensions. For network preview we run  guidedog serve docs --host 0.0.0.0 --port 8000 . --host ::  selects IPv6, while the default remains loopback. The preview has no authentication or TLS, so we use network binding only where this sharing is intended. The  diagram chapter  covers Graphviz and Typst together. The  Typst guide  explains every option, local imports, offline packages and migration from separate figure files. All six translated manuals include the new material. GDS 0014  records the reviewed implementation. Every unpacked platform archive exercises SVG and PNG diagram generation with an empty PATH.
