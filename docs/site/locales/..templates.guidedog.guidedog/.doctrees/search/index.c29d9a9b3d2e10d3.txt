We write the text once. Guidedog keeps the two editions in step. Read the manual Download Source code A plain text file goes in. Guidedog makes a web page and a book page from it.
what-it-does	What it does	What it does A website.  Pages with navigation, search, highlighted code, and light and dark themes, from Jinja templates we can change as much as we like. A PDF book.  Chapters, cross-references, figures, tables, footnotes, and an index, set by Typst with hyphenation for each language. reStructuredText and Markdown.  Directives, roles, toctrees, and cross-references work as Sphinx users expect, and MyST Markdown can sit next to them. Translations.  Gettext catalogs carry a project into other languages. Chinese, Japanese, Korean, and Hindi text is laid out correctly on screen and on paper. Diagrams, music, math, and API pages.  Graphviz and Typst diagrams, LilyPond music notation, LaTeX equations, and API reference for Rust, Python, and Odin, read from source code. Clear errors.  A message says what is wrong, where, and how to fix it. A failed build leaves the last good site in place.
one-program	One program	One program The release provides one  guidedog  executable with PDF typesetting and diagram rendering included. We download the archive for our system, unpack it, and start a project. On Windows we keep the bundled runtime files beside the executable. Configuration is a TOML file. Templates are plain files in our project, and we can edit them. The same command also manages static websites, publishes to GitHub Pages, and keeps discussion records through its linked  ssg ,  pages , and  dsc  plugins.
