Guidedog 1.0.0-beta.10
======================

A guitar part can now show tablature beside its staff: ``\new TabStaff`` draws the six strings of a guitar in standard tuning with a fret number for each note.
Guidedog chooses strings and frets as LilyPond does by default, and ``\1`` to ``\6`` name a note's string where we want another.

.. more::

The tab staff follows LilyPond's default tablature: a TAB clef, fret numbers centered on string lines that break around them so they read in light and dark themes, and no rhythm, which the staff above shows.
A tied note is repeated, in parentheses, only at the start of a line.
On the staff above, string numbers print as circled digits.
Metronome marks now print a note symbol for the beat, and ``\breathe`` prints a breath mark for singers and players.

The new practical task `Write a songbook <https://insanai.github.io/guidedog/manual/howto/songbook.html>`_ writes *Mary Had a Little Lamb* for voice, piano and guitar: the tune, two verses, chord names, a two-voice piano part, and the guitar part with tablature, explained step by step for students and built as a website and a book.
Every manual edition includes it.

Pages also read more evenly: a paragraph keeps its justification and hyphenation when one line is loose beside long inline code, and post lists, cards included, are typeset like the rest of the page.
`GDS 0016 <https://insanai.github.io/guidedog/discussions/records/0016-guitar-tablature.html>`_ records the tablature design.
