Guidedog 1.0.0-beta.9
=====================

We can now write musical scores directly in an RST or MyST ``lilypond`` directive without installing an external LilyPond binary.
Guidedog's in-process reader, rational score model and native engraver produce outlined Bravura SVG or PNG figures for websites and multi-system PDF books.
Up to four voices sound together on a staff, with local voice policies, ``\shiftOn`` and its relatives, mixed-rest placement and stacked dynamics.

.. more::

Scores support captions, alternative text, figure references, adaptive dark-mode web rendering and system-level PDF page breaks.
LilyPond 2.24 ``\markup`` works in scripts, tempo and rehearsal marks and instrument or staff-group names, while Scheme, layout and embedded-score markup are refused with placed diagnostics.
Score SVGs carry ``<title>`` and ``<desc>`` accessibility descriptions alongside localized musical summaries and native key-signature orthography across all nine built-in UI languages.

``guidedog convert`` names an unengraved LilyPond score file in a sentence, and ``--lang`` translates Guidedog's own labels in HTML and PDF output.
Built-in CLDR date formatting now covers Hindi and Korean alongside the other seven UI languages.
Temporary layout buffers in ``gd-engrave`` reserve and release through ``Options::scratch``, and ``--untrusted`` builds engrave inline notation while refusing external ``.ly`` files and ``\include``.

The `music chapter <https://insanai.github.io/guidedog/manual/topics/music.html>`_ covers directives, polyphony, lyrics, markup and trust boundaries, and `teaches a four-bar melody from Beethoven's Joy theme <https://insanai.github.io/guidedog/manual/topics/music.html#learn-from-beethoven-s-joy-theme>`_.
All six translated manuals, website editions and README files have been reviewed for native idiom and musical terminology.
`GDS 0015 <https://insanai.github.io/guidedog/discussions/records/0015-lilypond-music.html>`_ records the accepted design and qualification evidence, and every unpacked platform archive exercises native music engraving with an empty PATH.
